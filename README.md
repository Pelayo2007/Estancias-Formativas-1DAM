# 📚 Estancias Formativas - 1º DAM

Este repositorio contiene toda la documentación, diarios de aprendizaje y proyectos desarrollados durante mi periodo de **Estancias Formativas** correspondientes al primer curso del Ciclo Formativo de Grado Superior en **Desarrollo de Aplicaciones Multiplataforma (DAM)**.

## 📁 Estructura del Repositorio

El contenido está organizado de la siguiente manera para facilitar el seguimiento de las actividades:

* **[📂 Diarios](./Diarios):** Registro detallado de las actividades realizadas día a día en la empresa.
* **[📂 Datos Presupuestarios](./Datos%20Presupuestarios):** Documentación y archivos relacionados con el análisis de costes o gestión de presupuestos.
* **[📂 Personajes](./Personajes):** Posible documentación de perfiles de usuario (User Personas) o activos para el desarrollo de aplicaciones/juegos.
* **[📂 Web](./Web):** Código fuente y recursos del apartado de desarrollo web realizado durante las estancias.
* **[📂 docs](./docs):** Memorias, esquemas y documentación oficial del periodo formativo.

## 🛠️ Tecnologías y Herramientas Utilizadas

Durante estas estancias he puesto en práctica conocimientos de:

* **Desarrollo:** ![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)
* **Gestión:** Documentación técnica, control de versiones con Git y gestión presupuestaria.
* **Diseño:** Definición de personajes y lógica de aplicación.

## 🎯 Objetivos de las Estancias

1.  Aplicar los conocimientos de programación y bases de datos en un entorno laboral real.
2.  Desarrollar habilidades de comunicación y trabajo en equipo.
3.  Documentar el proceso de aprendizaje para la futura inserción profesional.

## 📋 Cómo visualizar la documentación

Para leer los diarios o la documentación técnica:
1. Navega a la carpeta correspondiente.
2. Haz clic en los archivos `.md` o `.pdf` para ver el contenido directamente en GitHub.
