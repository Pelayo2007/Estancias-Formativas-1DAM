Este repositorio contiene toda la documentación, diarios de aprendizaje y proyectos desarrollados de forma grupal durante nuestro periodo de **Estancias Formativas**, correspondientes al primer curso del Ciclo Formativo de Grado Superior en **Desarrollo de Aplicaciones Multiplataforma (DAM)**.

## 📁 Estructura del Repositorio

El contenido está organizado de la siguiente manera para facilitar el seguimiento de las actividades:

* **[📂 Diarios](./Diarios):** Registro detallado de las actividades realizadas día a día en la empresa por el grupo.
* **[📂 Datos Presupuestarios](./Datos%20Presupuestarios):** Documentación y archivos relacionados con el análisis de costes o gestión de presupuestos.
* **[📂 Personajes](./Personajes):** Definición de perfiles de usuario, activos o lógica de personajes para el desarrollo de aplicaciones.
* **[📂 Web](./Web):** Código fuente y recursos de los desarrollos web realizados durante las estancias.
* **[📂 docs](./docs):** Memorias grupales, esquemas y documentación oficial del periodo formativo.
